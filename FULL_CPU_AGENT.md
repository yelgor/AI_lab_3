`split.json`. Валідаційні рядки залиш відкладеними. Мета — виміряти
ефект збільшення вибірки й перевірити ансамбль із XLM-R першої епохи.
Повторне GPU-навчання для цієї задачі не потрібне.

1. Онови гілку `homework-3-pipeline` через `git pull --ff-only`.
   З попереднього логу визнач фактичний Python, шляхи до CSV, спліту
   та результатів. Звір параметри запуску на 120 000 із його
   `metrics.json`: coverage, max_chars, batch, epochs і cache_gib.
   Команда нижче відповідає відомому запуску з head, 2000 символів,
   batch 256 і двома епохами. Якщо параметри відрізняються, відтвори їх.
   Кеш вимкнено: попередня спроба перейшла в потоковий режим.
2. Якщо вже є готова модель з усієї fit-партиції і тими самими
   параметрами, використай її прогнози. Запуск `hash-full-distributed`
   також додай до відбору, якщо він існує: він перевіряє інше
   охоплення документа. Для чистого порівняння 120k проти full
   використовуй ту саму обробку тексту.
3. Запускай CPU окремим процесом і збережи лог часу та пікової RAM.
   Скрипт завантажує CSV у пам'ять, а розріджені матриці будує пакетами.
   У разі нестачі RAM при векторизації повтори з batch 128 у новому
   каталозі. Запиши зміну, бо вона змінює порядок оновлень SGD.

```bash
# Підстав фактичні шляхи з попереднього запуску.
PY=python
DATA="$PWD/data"
RUNS="$PWD/.local-training/runs"
SPLIT="$RUNS/split.json"

# Ліміт дорівнює кількості рядків fit. Скрипт використає їх усі.
FIT_ROWS=$("$PY" -c 'import json,sys; print(len(json.load(open(sys.argv[1]))["fit"]))' "$SPLIT") &&
/usr/bin/time -v "$PY" large_baseline.py --data "$DATA" --split "$SPLIT" \
  --fit-rows "$FIT_ROWS" --coverage head --max-chars 2000 \
  --batch 256 --epochs 2 --cache-gib 0 --out "$RUNS/hash-full-head"
```

Перевір, що `fit_rows` у новому `metrics.json` дорівнює `FIT_ROWS`.

`val.csv` та `test.csv` саме першої епохи XLM-R, з якої отримано
публічні 0.88326. Підстав фактичний каталог у `XLMR`. Якщо є лише
чекпойнт першої епохи, спочатку згенеруй із нього обидва набори
ймовірностей без навчання. Якщо артефакту немає, заверши CPU-порівняння
й явно повідом, що відбір із XLM-R ще не зроблено.
